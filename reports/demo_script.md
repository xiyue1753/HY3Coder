# Demo 视频脚本（2 分钟）

录制工具：OBS / 系统录屏，分辨率 1920×1080，含背景音乐（音量 20%）。
环境：`python -m src.cli serve` 已启动，http://127.0.0.1:8000。

## 分段

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0:00-0:08 | 开场标题卡："ReAgents v2 · 过程评估与错误定位系统"，副标题"犀牛鸟实战任务 2" | 这是一套面向可验证场景的过程评估系统：让 AI 的每一步思考都能被检查、被定位、被修正。 |
| 0:08-0:25 | CLI 运行 `run-eval` 的终端回放（或已录屏） | 评估模式：先让求解 Agent 产出结构化分步过程，再由双视角验证 Agent 独立审查，交叉复核后给出判定。 |
| 0:25-0:45 | 仪表盘"评估总览"：指标卡 + 分层退化曲线 + 错误类型分布 + 判定分布 | 量化结果一目了然：答案准确率、过程正确率、Wilson 置信区间；错误类型覆盖概念、计算、跳步、边界与复杂度。 |
| 0:45-1:05 | 切"单题回放"：选中一题，展示步骤时间线，错误步骤红框高亮 + 定位标注；若有修正模式，切轮次展示修订前后 | 这是核心：逐步过程回放。错误起始步骤被红框高亮，并给出定位与归类。 |
| 1:05-1:25 | 切"交互式解题"：输入"求 x²-3x+2=0 的根"，勾选"演示修正闭环"，实时展示求解→验证→（若失败）修订→重验证 | 更进一步：自定义题目实时演示 ReAct 修正闭环。验证反馈回流给求解 Agent，限 3 轮内收敛。 |
| 1:25-1:40 | 切"Golden 库"：展示几条陷阱样本（如"1 被当质数但用例恰好 n≥2"、"q=1 时指数写错却得同值"） | 这是沉默失败识别：答案正确但过程存在根本缺陷。golden 库专门验证评估器不被正确答案误导。 |
| 1:40-1:55 | 切"人工抽检"表 + CLI `audit` | 有效性验证：人工抽检 30-40 题标注真实错误步骤，计算定位命中率与误报率。 |
| 1:55-2:00 | 收尾卡："源码/设计文档/800+ 题集/完整结果与分析报告已随交付物提供" | 完整交付：800+ 分层题集、评估结果、分析报告、27 项自动化测试，全部可复现。 |

## 录制要点

1. 全流程先**完整彩排一遍**再正式录，避免卡顿。
2. 交互式解题演示若网络慢，可提前预取一次结果缓存到页面。
3. 字幕用浅色大字、底部安全区，不遮挡指标卡。
4. 演示中保持一个"错误→修正"的成功案例（预选好题号）。
