## 7. Golden 沉默失败样本库

共 23 条（算法 15 / 数学 8），全部为「答案正确但过程有缺陷」陷阱样本：

- `GM001` [math] 求方程 x^2-3x+2=0 的根。 — 真实缺陷：跳步推导（陷阱用韦达定理『根之和 3、根之积 2，故 x=1,2』，未证明解唯一性与推导过程；答案正确…）
- `GM002` [math] 求 sin30° 的值。 — 真实缺陷：跳步推导（陷阱直接给出 sin30°=1/2（记忆值），无任何推导或单位圆/三角形依据；答案正确但过程不可验证…）
- `GM003` [math] 解不等式 x²<4。 — 真实缺陷：逻辑缺陷（陷阱只推导 x<2（开方后漏 x>-2 分支），却在最终答案写 -2<x<2；过程无法推出最终答案（自相矛盾）…）
- `GM004` [math] 求半径 r=2 的圆面积（结果保留 π）。 — 真实缺陷：格式不符（陷阱计算 4π≈12.56 并输出小数，题目明确要求保留 π 形式；数值等价但格式不符…）
- `GM005` [math] 掷两枚骰子，和为 7 的概率。 — 真实缺陷：概念理解错误（陷阱把 6 种有序组合 (1,6)..(6,1) 误用组合数 C(6,1)=6 计数，声明『无序组合』；恰好值同为 6，…）
- `GM006` [math] 计算 (0+2)² 的值。 — 真实缺陷：概念理解错误（陷阱用 (a+b)²=a²+b²（把平方展开误当分配律）计算，恰好 a=0 使两路结果都为 4，概念错误被掩盖…）
- `GM007` [math] 等比数列 a1=2，公比 q=1，求 a5。 — 真实缺陷：概念理解错误（陷阱写 a5=a1·q^5（应为 q^(5-1)=q^4），恰逢 q=1 使 q^5=q^4=1，指数错误被掩盖，答案碰…）
- `GM008` [math] 证明恒等式 sin²x+cos²x=1。 — 真实缺陷：概念理解错误（陷阱用『直角三角形勾股定理』证明该恒等式（循环论证：勾股定理依赖三角定义），概念错误但结论正确…）
- `GA001` [algorithm] 判断整数 n(2≤n≤10^4) 是否为质数，是输出 yes，否则 no。 — 真实缺陷：概念理解错误（陷阱把 1 当质数（is_prime 缺 n<2 分支），但公开/隐藏用例恰好 n≥2，答案全部正确…）
- `GA002` [algorithm] 给定有序整数数组，输出去重后的数组（保持原顺序）。 — 真实缺陷：概念理解错误（陷阱用 list(set(a)) 去重并宣称保持原顺序，Python set 无序；恰好输入升序，set 迭代序碰巧与升…）
- `GA003` [algorithm] 输入整数 n(0≤n≤10^9)，输出 1+2+...+n。 — 真实缺陷：missing_condition（陷阱 n*(n+1)//2 未处理 n=0（公式对 n=0 也应得 0，实现却写成 range 循环从 1 开始求和，n…）
- `GA004` [algorithm] 按数值对数组稳定排序并输出（相等元素保持原相对顺序）。 — 真实缺陷：概念理解错误（陷阱用快速排序并宣称稳定；Python 快排分区对相等元素会交换，但输入恰好无相等元素，输出碰巧正确…）
- `GA005` [algorithm] 求第 n(0≤n≤30) 个斐波那契数（F0=0,F1=1）。 — 真实缺陷：复杂度不达标（陷阱递归实现 fib(n)=fib(n-1)+fib(n-2) 声明时间复杂度 O(n)，实际 O(2^n)；用例 n≤…）
- `GA006` [algorithm] 求数组的最大子数组和（n≤10^4）。 — 真实缺陷：逻辑缺陷（陷阱用 O(n^3) 枚举全部子数组并声明时间复杂度 O(n)；用例 n 小恰好通过，但数据范围 10^4 下必然超时…）
- `GA007` [algorithm] 原地反转字符串并输出（不使用额外 O(n) 空间）。 — 真实缺陷：概念理解错误（陷阱用 s[::-1] 完成反转却宣称『原地反转，O(1) 空间』；切片实际创建新字符串，答案正确但空间声明错误…）
- `GA008` [algorithm] 求数组的中位数（未保证输入有序）。 — 真实缺陷：missing_condition（陷阱直接取排序中间下标 arr[n//2] 而不排序，宣称『输入已排序』；恰好用例是有序输入…）
- `GA009` [algorithm] 将非负整数 n 转为二进制字符串输出。 — 真实缺陷：边界条件（陷阱 while n>0 收集余数，n=0 时返回空字符串；用例恰好不含 0…）

- `GA011` [algorithm] 求两个正整数 a,b 的最大公约数。 — 真实缺陷：逻辑缺陷（陷阱辗转相除递归无终止条件 b=0，宣称『欧几里得算法正确』；用例恰好 b>0 不触发死循环…）
- `GA012` [algorithm] 输出矩阵的转置（m 行 n 列）。 — 真实缺陷：逻辑缺陷（陷阱用 list(zip(*m)) 反向？实现将行翻转而非转置；恰好测试用 2x2 对称矩阵，翻转与转置输出相同…）
- `GA013` [algorithm] 计算 a^n (0≤n≤10^9)，输出结果。 — 真实缺陷：复杂度不达标（陷阱用 for 循环累乘 n 次并声明复杂度 O(log n)（快速幂未实现）；用例 n 恰好小…）
- `GA014` [algorithm] n 个元素数组，q 次查询区间和（n,q≤10^5）。 — 真实缺陷：复杂度不达标（陷阱每次查询内层循环累加（O(nq)）却声明 O(n+q)；用例 q 恰好小…）
- `GA015` [algorithm] 输入 n 个整数，每行输出一个数的平方。 — 真实缺陷：格式不符（陷阱把全部结果 print(' '.join(...)) 输出在一行，宣称符合要求；恰好用例 n=1 时单行与多行相同…）
